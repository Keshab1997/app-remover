# Google Play listing assets

- `app-icon-512.png`: Play listing icon, matching the app's launcher branding.
- `feature-graphic-1024x500.png`: feature graphic with an AI-generated background.
- `phone-screenshots/`: three 1080 × 1920 PNG phone screenshot mockups.
  Each combines an AI-designed background and headline with a real screenshot
  provided by the developer; the screenshot content is not AI-generated.

Upload the screenshots in numerical order. Review the visible installed-app
names and icons and confirm the screenshots match the release before publishing.
These screenshots reveal the developer's installed apps and device status. Replace
with a clean test device's captures if those details should not be public.

Check current [Play graphic requirements](https://support.google.com/googleplay/android-developer/answer/9866151)
before upload. These files do not publish the store listing by themselves.
